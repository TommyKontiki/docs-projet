Prérequis

Vérifier les outils installés

Chaque commande doit afficher un numéro de version.

node -v
npm -v
php -v
composer -V
mysql --version

Choisir la version de Node.js (nvm)

Utile si plusieurs versions de Node sont installées.

nvm list
nvm use <version>

Serveur PHP (backend et landing pages)

Installer les dépendances

# à adapter : chemin du projet
cd chemin\vers\kontiki-ws-collections
composer install

# seulement si phpdotenv n'est pas déjà dans composer.json
composer require vlucas/phpdotenv

Préparer le fichier .env

Les identifiants ne doivent plus être écrits en dur dans le code. Crée un fichier .env à la racine du projet PHP, avec les noms de variables que ton code lit.

# exemple de forme, remplace par tes propres variables
NOM_VARIABLE=valeur
Ne jamais publier le .env Ajoute .env dans le fichier .gitignore avant tout git push.

Démarrer le serveur intégré

Les liens des KITs pointent vers 127.0.0.1:8200 : c'est ce serveur qui sert les landing pages.

php -S 127.0.0.1:8200

Afficher les erreurs PHP (pour éviter les pages blanches)

php -d display_errors=1 -d error_reporting=E_ALL -S 127.0.0.1:8200

Tester qu'un endpoint répond

Affiche le code HTTP et les en-têtes, sans télécharger la page.

curl -i http://127.0.0.1:8200/api/insert.php

Client Nuxt (Leadit)

Installer et lancer en développement

# à adapter : chemin du projet
cd chemin\vers\LEAD-IT
npm install
npm run dev

Le projet est une SPA avec une baseURL en /leadit/3.17/ : l'adresse et le port exacts s'affichent dans le terminal, ajoute ce préfixe si besoin.

Indiquer l'adresse de l'API (variable d'environnement)

Dans le fichier .env du projet Nuxt. L'adresse est lue par runtimeConfig.public.apiBackend.

NUXT_PUBLIC_API_BACKEND=<adresse de l'API>

Générer la version à déployer

npm run generate
npm run preview

Le résultat se trouve dans .output/public. Pour un site généré, la valeur du .env est prise au moment de la génération.

Base de données MySQL

Se connecter et explorer

mysql -u root -p
SHOW DATABASES;
USE <nom_base>;
SHOW TABLES;
SELECT COUNT(*) FROM <nom_table>;

Sauvegarder et restaurer

mysqldump -u root -p <nom_base> > sauvegarde.sql
mysql -u root -p <nom_base> < sauvegarde.sql

KITs emailing

Prévisualiser un KIT en local

Ouvre le fichier dans le navigateur. Les images doivent se trouver dans le dossier images/ à côté du fichier.

start kit-mutuelle.html
Pour tester le clic Les boutons mènent vers 127.0.0.1:8200 : lance d'abord le serveur PHP ci-dessus.

Git

Envoyer ses modifications

git status
git add .
git commit -m "Description de la modification"
git push origin master

Remplace master par main si c'est le nom de ta branche.

Récupérer les changements des autres

git pull origin master
