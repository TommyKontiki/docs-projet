Toutes les commandes dans l'ordre. Les parties entre <chevrons> ou marquées « à adapter » dépendent de ton poste.

Serveur PHP (WS Colections)

Démarrer le serveur du backend

php -S 0.0.0.0:8000

Afficher les erreurs PHP (pour éviter les pages blanches)

php -d display_errors=1 -d error_reporting=E_ALL -S 0.0.0.0:8000

Lancer le serveur de NUXT

npm run dev -- --host 0.0.0.0
