01 · Commandes

Lancer le projet

Backend PHP(WS Collections) Client Nuxt Landing pages Landing page pour le sport Livraison pour ANDRE Livraison pour TOMMY

Serveur PHP (WS Colections)

Démarrer le serveur du backend

php -S 0.0.0.0:8000

Afficher les erreurs PHP (pour éviter les pages blanches)

php -d display_errors=1 -d error_reporting=E_ALL -S 0.0.0.0:8000

Client Nuxt (Leadit)

Utiliser la version 16 de node

nvm use 16

Lancer le serveur de NUXT

npm run dev -- --host 0.0.0.0

Landing pages

Lancer le serveur pour le LPs

php -S 0.0.0.0:8200

Landing pages pour le campagne de sport

Utiliser la version 24 de node

nvm use 24

Lancer le serveur pour le landing page de sport(serveur de vue)

npm run dev -- --host 0.0.0.0

Mr Andre (livraison de leads de sport)

Lancer le serveur d'API pour livrer les leads pour le client 1(laravel)

php artisan serve --host 0.0.0.0 --port 8081

Mr Tommy (livraison de leads de sport)

Lancer le serveur d'API pour livrer les leads pour le client 2(django)

python manage.py runserver 0.0.0.0:8082
