Démarrage rapide

Deux terminaux : un pour le serveur PHP, un pour Nuxt. Le détail est dans la page Commandes.

# à adapter : chemin du projet PHP
cd chemin\vers\kontiki-ws-collections
php -S 127.0.0.1:8200
# à adapter : chemin du projet Nuxt
cd chemin\vers\LEAD-IT
npm run dev

Mettre cette documentation en ligne (GitHub Pages)

Le site est 100 % statique : aucun build, aucune dépendance.

  1. Créer un dépôt GitHubPar exemple documentation-leads, en public.
  2. Envoyer les fichiers 
    git init
git add .
git commit -m "Documentation du projet"
git branch -M main
git remote add origin https://github.com/<utilisateur>/<depot>.git
git push -u origin main
  3. Activer PagesDans le dépôt : Settings → Pages → Build and deployment → Deploy from a branch, branche main, dossier / (root), puis Save.
  4. Ouvrir le siteAprès une minute ou deux : https://<utilisateur>.github.io/<depot>/
À savoir Tous les liens du site sont relatifs, il fonctionne donc aussi bien à la racine qu'en sous-dossier. Pour ajouter une page au menu, il suffit d'ajouter une ligne dans assets/app.js (tableau PAGES).

Lexique

Lead
Contact qui a manifesté de l'intérêt pour un produit ou un service et laissé ses coordonnées.
KIT
Email HTML envoyé aux clients, avec un bouton qui mène vers une landing page.
Landing page
Page d'atterrissage avec un formulaire. La validation du formulaire transforme le client en lead.
Leadit
Projet de gestion des leads : consultation, suivi et export.
Partenaire
Entreprise qui achète les leads livrés.
ePigeon
Plateforme utilisée pour envoyer les KITs par email.
